# quant-lab

An evidence-first quant research lab, run from your own Mac: a data lake built from free sources, a backtest
engine with realistic costs, a 10-stage validation gauntlet, a research inbox that reads new papers with a
local AI model, and strategy mining. Every backtest is recorded in a trial ledger, so the statistics stay
honest about how many things were tried.

> Research and paper trading only. Nothing in this repo places real-money orders.

Status: being built milestone by milestone. See `ROADMAP.md` for the plan and the milestone list below
for what's done.

| Milestone | What it adds | Status |
|---|---|---|
| M0 | Project, ledger, audit log, Lab API, web shell | in progress |
| M1 | Data lake from free sources + Data Health page | planned |
| M2 | Backtest engine with costs + Backtest Studio | planned |

| M5 | Strategy mining | planned |
